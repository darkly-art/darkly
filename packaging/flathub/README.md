# art.darkly.Darkly

Flathub packaging for [Darkly](https://github.com/darkly-art/darkly), generated
by `scripts/flathub.sh` in that repository at the commit the manifest pins.
Nothing here is edited by hand: change the template in `packaging/flathub/`
or the tree upstream and rerun the script. The release pipeline does that on
every tag and pushes the result here.
